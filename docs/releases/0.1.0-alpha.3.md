# Desktop candidate 0.1.0-alpha.3

Verified 2026-10-07. **Status: built and exercised developer candidates; not a published release or trusted commercial distribution.** Runtime/build source: `ec1bb62709f9c392b5ddf52549cbe004890b26e7`. All verified packages embed that revision and `sourceDirty: false`. Later documentation commits do not change these bytes. Existing public alpha.2 downloads remain immutable.

## What changed

macOS gains a drag-to-Applications DMG alongside ZIP. Windows uses an assisted per-user NSIS installer configured to retain workspace data on uninstall, and does not automatically launch into a user's workspace on completion. Linux remains an AppImage candidate. All platform jobs exercise the actual distribution, rather than electron-builder's staging directory.

The desktop now reopens after closing its last macOS window, opens its allowlisted setup guide in the browser, closes promptly despite incomplete loopback requests, and cleans up discovery files. SQLite applies owner-only POSIX file modes to its database and live journal files before use and refuses a newer schema before changing journal mode. Windows ACL privacy remains unverified. The source landing presents the available free preview; optional paid offers remain research hypotheses.

## Remaining release gates

Publisher signing/notarization and Windows signing are not configured. The pending maintainer decision is whether to distribute a clearly labeled free developer preview or supply publisher credentials for a trusted release. There is no new public alpha.3 release, no automatic update feed, and no paid checkout. Do not tell users to disable OS protections.

Windows and Linux evidence comes from their specified CI runners; interactive installer prompts, desktop accessibility, and previous-version upgrades on those systems remain unverified. Windows post-uninstall workspace retention also needs a dedicated check: the runtime smoke removes its disposable workspace before uninstall runs. Linux uses the actual AppImage's extraction entrypoint and its shipped runtime under Xvfb with a scoped root-owned sandbox helper. It does not prove direct FUSE launch or desktop integration on an arbitrary Linux machine. No global AppArmor or sandbox policy is disabled.

The build dependency audit has one known moderate `sprintf-js` advisory propagated through development tooling; the production-only audit reported zero known vulnerabilities. The independent review records the scoped reachability assessment and temporary exception. This is not a security certification.

This is a single-user local desktop workbench. Full collaboration, programmable documents/tables, enterprise controls, real-provider AI validation and commercial services retain their separate requirements in the capability ledger. Passing these installer checks does not establish the full product roadmap or enterprise readiness.
